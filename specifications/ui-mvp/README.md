Это единый пакет спецификации для разработки нового интерфейса Palissage. Он описывает целевой результат, а не утверждает, что перечисленные возможности уже реализованы. В рамках подготовки пакета код приложения и контрактов не менялся, изображения не загружались в приложение, deployment не выполнялся.

Основная идея: **прямая торговля вином между винодельней и профессиональным покупателем, с понятным жизненным циклом партии от предложения до получения бутылок**. Для комиссии — выразительный публичный сайт и воспроизводимая демонстрация. Для участников пилота — предметные рабочие экраны с достоверными состояниями.

## Решения, принятые для этой версии ТЗ

- Основной язык UI — английский; французский — второй. Все видимые строки должны иметь EN/FR варианты перед демонстрационным релизом. Это рабочее предположение, не полученное подтверждение предпочтения владельца.
- Основной вход — **Explore the demo**, без кошелька; testnet доступен отдельным осознанным входом. Сам сайт ориентирован на B2B, кошелёк появляется в контексте testnet-действия.
- Полная переработка страниц разрешена. Базовый React/Vite стек можно сохранить; текущая верстка не является ограничением.
- Визуальное направление — **«Живая шпалера»**: светлый известняк, винный акцент, виноградная лоза, крупная редакционная фотография, линия жизненного цикла партии.
- Основной продукт включает первичную продажу, En Primeur, перепродажу, доставку, проверку участников и партий. Паспорт бутылки — короткий публичный эпилог, без отдельной социальной сети.
- Все демонстрационные винодельни, покупатели, цены и операции — явно обозначенные синтетические данные. Имеющиеся в mock реальные бренды не означают подтверждённого партнёрства.

## Быстрый старт для следующего агента

Прочитать 01 и соответствующие разделы 02–06. Получить от координатора конкретный task ID из 07 и **точный список разрешённых существующих файлов**. Сделать только этот этап. Сдать изменённые файлы, доказательства приёмки и оставшиеся ограничения. Реализация и её результаты проверяются отдельно по этапам 07–08.
